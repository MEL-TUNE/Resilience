# 彼岸リオ Reader 1.3.1 — 花と月

彼岸花と三日月をあしらった長文読み上げアプリです。

## はじめ方
1. ZIP全体を展開します。
2. index.htmlをChromeまたはEdgeなどのブラウザで開きます。
3. 文章を貼り付け、音声を選んで「再生 / 続きから」を押します。

画面下の「読み飛ばし・表示設定」では表示名と6場面の台詞を編集できます。本文と読み上げ位置はブラウザに保存されます。重要な文章はTXT保存を併用してください。

## 旧版から移す場合
元の版で「TXT保存」「設定を書き出す」を行い、新版で「TXT / MDを開く」「設定を読み込む」を使ってください。同じ配信元での上書き更新では既存の保存領域を使用し、旧版の標準台詞のみを新しい文体に移行します。独自の台詞は維持します。

## 特徴
- TXT / Markdown読み込み、TXT保存、整形後プレビュー
- 再生・一時停止・停止・前後移動、音声・速度・音程の選択
- 区切り記号やURLの読み飛ばし、設定の書き出し・読み込み
- モバイル幅への対応、SVGアイコン、Web公開時のService Worker

入力本文は書き換えません。会話AIやリオ専用音声は含みません。音声は端末・ブラウザが提供し、その音声によってネットワークを利用する場合があります。

販売用の資料（利用規約・商品説明のひな形、更新履歴、確認結果など）は、このフォルダには含めていません。配布用ZIPに同梱しています。

## 絵文字・顔文字の読み飛ばし
絵文字（肌色・国旗・家族などの連結絵文字・数字キー絵文字を含む）と一般的な顔文字を読み上げ用の文章から除きます。入力欄やTXT保存の原文は維持します。「整形後を見る」で確認できます。顔文字は自由な文字の組み合わせのため、すべての独自表現を完全に判定することはできません。残る顔文字は設定の「部分一致で読み飛ばす文字列」で指定できますが、この指定は該当行全体を除外します。

## 着せ替え
「アイコン・色の着せ替え」から、標準紋章・花月の宝飾アイコン・自分の画像を選べます。4つの配色見本と背景・読書面・アクセント・装飾の色を自由に変更できます。プレビューで確認後「着せ替えを保存」で反映します。閉じると未保存の変更は破棄されます。標準に戻す操作も保存前に取り消せます。

自分の画像はPNG/JPEG/WebP（8MBまで）に対応し、中央の正方形へ縮小してブラウザに保存します。画像の外部送信はありません。設定書き出しには画像・配色も含まれます。キャラクターの名前・6場面の台詞は「読み飛ばし・表示設定」で変更できます。名前は画面見出しとタブ名にも反映します。変更対象はアプリ内のアイコンで、インストール済みPWAのホーム画面アイコンは変わりません。


## 配色とアイコンの連動（v1.3.0）
花と月・夜の書斎は花月の宝飾、藤の便りは藤月の宝飾、木陰は木陰の月飾り、蜂蜜の書斎はチヅルの書香を選びます。自分の画像を選んでいる場合は画像を維持して配色だけを変更します。4色の個別調整ではアイコンを変更しません。選択は保存するまで本画面に反映しません。名前や台詞は着せ替えで変更しません。
アイコン画像（PNG 4枚）の原画像は1254×1254pxです（チヅルの画像は生成時に2048pxを指定しましたが、実際の出力寸法を記載しています）。v1.3.1から、同梱版は表示サイズに合わせて384×384pxへ縮小しています。原寸画像は配布ZIP v1.3.0に含まれています。
