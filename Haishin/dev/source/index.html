                歌枠管理シートとつなぐ（曲・音源の読み込み、配信ログへの書き込み）
                

                歌枠管理シート（Googleスプレッドシート）の曲と音源を、曲リストに読み込めます。読み込んだ曲は、セトリ・曲リストの「▶」から音源へ飛べます。方法は2つあります。
                

                A. 貼り付けで読み込む（準備なし）
                

                シートの「曲」タブか「音源」タブで、見出しの行から最後の行まで（列はAから最後まで）選んでコピーし、下に貼り付けて「読み込む」を押します。曲タブ→音源タブの順に読み込むと、シートの表記のまま曲と音源がつながります。同じ曲・同じ音源は重ねて登録しません。
                


                

                

                B. Apps Script でつなぐ（読み込み、配信ログへの書き込み、シートの編集）
                

                いまのコードは版3です（シートの編集・ラベル・編集の記録・控え）。版2をお使いなら、Apps Script のコードを全部置き換えて保存し、「デプロイ」→「デプロイを管理」→ 鉛筆の印 → バージョン「新バージョン」→「デプロイ」で入れ替えます（URLと合言葉はそのままです。合言葉の行は、書き換えた合言葉に直してから保存します）。
                

                1. シートを開き、メニューの「拡張機能」→「Apps Script」を開きます。
                2. 下の「コードをコピー」で写したコードを、最初からあるコードと全部置き換えて貼り付けます。
                3. コードの中の ここに合言葉 を、自分だけの合言葉（英数字で12文字以上がおすすめ）に書き換えて保存します。
                4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、次のユーザーとして実行「自分」、アクセスできるユーザー「全員」でデプロイし、表示される許可の画面で許可します。
                5. 出てきた「ウェブアプリ」のURL（…/exec）と合言葉を、下に入れて「保存して確かめる」を押します。
                

                

                

                

                

                URLと合言葉は、このブラウザの中だけに保存します（設定ファイルや書き出しには入りません）。URLと合言葉を知っている人は誰でもシートを読み書きできるので、人に見せないでください。配信が終わったら「④ これまでの記録」の回を開き、「歌枠管理シートへ」から配信ログに送れます。シートに書き込むのは手で入力する列だけで、自動で計算する列には書きません。

                URLは「https://www.youtube.com/@名前」か「https://www.youtube.com/channel/UC…」の形で入れます（@名前だけでも可）。メモは使用条件の控えです。初期値は歌枠管理シートの提供者タブ（2026年10月30日時点）から写したもので、規約が変わることがあるため、使う前に提供者の原文で確かめる想定です。
                

                

                KARAOKE / SOUND
                伴奏の音をアプリに取り込む
                

                YouTubeなどを開いた別のタブの音を、このアプリの音（モニター・録音・動画・配信用の出力）に混ぜます。再生・一時停止・シークはそのタブ側で、音量はここで調整します。埋め込みは使いません。
                

                

                停止中
                



                自動のフェードアウトは、取り込んだ伴奏タブの音が約2秒以上の無音のあとに鳴り始めたときに働きます。購入音源をアプリの外で流すときなど、伴奏を取り込んでいない場合は「歌い始め」ボタンを使います。
                選ぶ画面では「Chromeタブ」（Edgeでは「タブ」）から伴奏のタブを選び、「タブの音声も共有する」をオンにします。パソコン版のChrome・Edge向けの機能で、スマートフォンでは使えません。伴奏は効果音・BGMと同じく自動で小さくなる処理（ダッキング）の対象外です。モニター音がオフ（スピーカー判定など）のときは、上の「タブ側では鳴らさない」をオンにしていると伴奏が聞こえません。
                

                

                

                AI CHARACTER / VOICE
                

                AIキャラ・声
                

                AIキャラクター（たとえば彼岸リオ）に話してもらうための、声の準備の場所です。声の合成エンジン（AivisSpeech など）とのつなぎ込みと、AIキャラクターの口パクは、これから順に足していきます。
                

                ボイス録り（音声モデルの学習用の録音）
                

                読み上げる文を1文ずつ表示して録音し、音割れ・声の小ささ・雑音・短すぎをその場で確かめます。録った声は、1文1ファイルのWAVと「ファイル名|話者名|JP|文」の一覧（Style-Bert-VITS2 などの学習用の形式）にまとめて、ZIPで書き出せます。声のモデルを作る（学習する）作業は、GPUのあるPCや Google Colab などで別に行います。マイクは、ブラウザの音声加工（エコー除去・雑音抑制・自動音量）を切った状態で開きます。

                    配信に届く音（配信用の出力先）

                    配信モードでは、マイクの声はこのアプリから出しません（口パクの判定にだけ使います）。OBSではマイク（AG03など）を直接取り込み、このアプリの音はブラウザの音として取り込みます。下の出力先は、効果音・BGMだけを仮想オーディオ機器へ分けて送りたいときに使います。動画モードでは、マイク＋効果音・BGM・環境音のミックスを送ります。
                    配信用の出力先を選ぶと、そのミックス（ダッキング・リミッター・ミュート反映済み）を、その音声機器へ別に送ります。仮想オーディオ機器を選び、配信ソフトではその機器だけを音声として取り込む構成を想定しています。普段のイヤホン・ヘッドホンを選ぶと、自分の声が遅れて聞こえます。
