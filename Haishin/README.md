# 配信処オトノハ（テスト版）

PNGTuber（立ち絵の口パク・まばたき）と、声・BGM・効果音・環境音の合成をまとめた、配信・収録用のブラウザアプリです。`index.html` 1ファイルで動きます。

公開場所：https://mel-tune.github.io/Resilience/Haishin/

現在の版：STUDIO 0.11.11（着せ替えに「雪見おとの色」8色）

編集用のソースは `dev/source/` にあります（JavaScript は `js/audio/` と `js/visual/` に機能ごとに分かれています）。`dev` で `python build.py` を実行すると `dev/index.html` ができるので、それをこのフォルダの `index.html` に置きます。

## 0.11.10 で変わったこと

低スペックのノートパソコンでの重さを減らしました。グラフィックの弱いPC（ソフトウェア描画）に近い条件で測ると、ページの負荷の大半は、映像を描く処理ではなく、大きな映像をページの中で縮めて見せる処理と、音量メーターなどの表示を毎コマ書き換えることでした。

- **軽量モードのプレビュー**：軽量モードでは、この画面のプレビューを、見えている大きさの小さな写しにして、1秒に8回だけ更新します。配信用ウインドウ・アプリ表示・内蔵の収録には、これまでどおり本体の映像が行くので、なめらかさは変わりません。プレビューの上でのドラッグなどの操作も、これまでどおりです。測った条件（ソフトウェア描画・CPU を6分の1に落とした状態・縦長の映像・30fps）では、ページの負荷が 9割ほどから 4割ほどに下がりました。
- **音量メーター・状態の表示**：値が変わったときだけ書き換えるようにしました（無音のあいだは描き直しません）。音声収録の画面では、同じ条件で 8割ほどだった負荷が 1割未満になりました。軽量モードでなくても効きます。

GPU の効くPCでは、もともとこの2つの負荷は小さいので、違いはほとんど感じられないはずです。

## 0.11.9 で変わったこと

**漫符のハート**：途中で止まって見えたのを直しました。頭の左右（顔にかからない所）から出て、止まらずにまっすぐ昇り、画面の上の外へ抜けます。頭が低い位置にあるほど、昇る道のりも長くなります。0.11.7 で足した「頭が画面の上の端に近いとき、出る高さを下げて左右へ広げる」処理は外しました（顔の上に重なって止まったように見えた原因です）。

**漫符のきらめき（✧）**：頭の上の弧に等間隔で並べ、光の線を放射状に出していたのをやめ、頭のまわり（顔の外）に、大きさ・位置・角度をばらばらに散らすようにしました。出る時刻・消える時刻も1つずつ違い、少しまたたきます。近すぎる位置に重なったときだけ置き直します。

**ルーレット**：項目の文字の大きさを、扇の長さと幅の両方に収まる、いちばん大きい大きさにしました。これまでは上限が決まっていて、1文字の項目がとても小さく見えていました。長い項目はこれまでどおり小さくなり、それでも入らないときだけ末尾を省きます。

**歌枠ノート（セトリと音源）**
- 音源のボタンは、提供者の略称で出します。歌枠管理シートの「提供者」タブに「略称（セトリ表示用・空欄なら自動）」の列を足し、Hiro・歌っちゃ王・BOX・カラオケ音源ch・Dagger Hearts を入れました（シートの列なので、あとから自由に直せます）。空欄の提供者は、オトノハが自動で短くします（「」の中、絵文字の後ろの名前など）。ボタンの幅にも上限を付けました。
- セトリの行は、どの曲も同じ形にそろえました。ふつうは2行で、1行目が「♪ 歌い始め」と曲名（1行。入りきらない分は「…」で省き、カーソルを重ねると全体が出ます）、2行目が音源・📁・🗒️ と ↑↓外す です。セトリの幅が広いとき（760px 以上）は1行にまとめます。音源のボタンはどれも同じ幅です。
- 配信先（YouTube／IRIAM／17LIVE）を選ぶと、その配信先で使えない音源に ✕ を付けて薄く出します。可否が未確認の音源は ？ です。判定は、シートの「音源」タブの「個別：…」の列があればそれを、なければ「提供者」タブの可否を使います。YouTube は「YouTube配信で使用」、IRIAM と 17LIVE は「YouTube以外の配信」と「収益化済み配信」の両方を見て、17LIVE では管理団体が NexTone だけの曲を外します（IRIAM は JASRAC と NexTone の両方と提携しているため外しません）。
- 音源ファイルの保存場所（シートの「音源ファイルの保存場所」。Googleドライブのリンクなど）がある音源は、📁 のボタンで開けます。URL のない購入音源も、これで出るようになりました。
- シートの「歌詞ページのURL」が入っている曲にだけ、🗒️ のボタンを出します（押すと歌詞ページを開きます）。
- 「▶ セトリの音源をまとめて開く」で、セトリの曲の YouTube の音源を1曲に1つずつ、新しいタブで開きます。使う音源は、その曲で最後に開いた音源、なければ配信先で使える最初の音源です。ブラウザがポップアップを止めた場合は1件しか開かないので、開けなかった分もリンクの一覧で出します（このページのポップアップを「常に許可」にすると、まとめて開けます）。
- 歌枠管理シートを読み込むと、管理団体・歌詞ページの URL・音源ごとの可否・動画内の歌詞表示・音源ファイルの保存場所を、曲リストにも写します。

**歌枠ガチャ**（歌枠ノートの「① セトリ」の下）：ラベルでしぼってランダムで1曲出します。ラベルはシートの「ラベル一覧」の分類ごとに、記号と曲数を付けて並べます。「どれかが付いた曲」と「全部付いた曲」を選べます。セトリに入っている曲・今回の記録で歌った曲・配信先で使える音源がない曲は、出さないようにできます。出るときは曲名がぱらぱら変わってから止まります。出た曲は、セトリへ入れる・歌い始めを記録する・音源を開く・配信画面に出す（「🎲 企画」の歌枠ルーレットのカードとして。その冊がなければ作ります）ができます。ラベルから選出した曲の一覧も開けます。

**カラオケ音源を探す**：歌枠管理シートの「提供者」タブにあって、ここにまだないチャンネル（YouTube の URL があるもの）を足します。一度足したチャンネルは覚えておくので、消したあとに足し直すことはありません。

**Apps Script 版5**：「提供者」タブの「略称」列を読み書きします（版4のままだと略称の列は読み込まれず、自動で短くした名前を出します）。そのほかは版4と同じです。

## 0.11.7 で直したこと

**アプリと並べる立ち絵（キャラクターだけ）**
- キャラクターの枠が、立ち絵の高さの1.15倍の幅で作られていたため、細い立ち絵は枠の真ん中に立ち、「横の位置」を右端（100%）にしても右に寄らず、アプリの真ん中にかかっていました。枠を、キャラクターがちょうど入る幅にしました。右端・左端に寄せると、その端に立ちます。
- 「アプリとの関係」を足しました。「アプリの上に重ねる」（これまで）と、「アプリの横に並べる（重ねない）」。横に並べると、キャラクターの幅だけアプリを狭めて、隣に立たせます（横の位置が 50 より小さいと左、大きいと右）。ページ内の確認用の枠と、OBS 用の別ウインドウの両方に効きます。
- ページ内の確認用の枠で、キャラクターの置き場所が決まる前に枠の外にあると、一度も描かれないことがあったのを直しました。

**マスコットの大きさが戻ってしまう**
- 設定を書くのは、操作が止まってから0.4〜2秒後でした。iPhone でつまみを動かしてすぐ別のアプリへ移ると、その変更が保存されないことがありました。画面を離れる・裏へ回るときに、その場で書くようにしました。
- 向き（横・縦・3:4）を切り替えたとき、0.10.4 までの控え（「直した印」がないもの）を「写し」とみなして換算していたため、大きさが変わって見えました。印のない控えは、そのまま戻すようにしました。

**ハートの漫符が見えない**
- ハートは頭の上へ昇るので、頭が画面の上の端に近いと、ほとんど画面の外に出て見えませんでした（0.11.2 で、汗が押し下げられる動きをやめたことで起きていました）。昇る道のりが入りきらない分だけ低いところから出し、顔にかからないよう左右へ広げます。
- 漫符の大きさ・位置のつまみを動かしている間は、その漫符を出して、どこに出るかをその場で見せます。

**セリフ・お題・スロットの文字**
- 「吹き出しの位置」の隣に「文字の大きさ」（小さく・ふつう・少し大きく・大きく・とても大きく）を足しました。セリフの吹き出し、お題のカード、スロットのカードに効きます。
- 小さすぎた見出し（お題の札「架空メロつきコメント」など、名前の行「— 星屑ミトン」、スロットの「役柄 × セリフ」）を、ふつうの大きさでも大きくしました。

- 設定ファイル：「すべてを書き出す（.live）」と「効果音・BGMだけ書き出す（.kissa）」を選べます。.live には立ち絵・名義・降らせる画像・背景・台本・映像設定も入ります。読み込みは .live／.kissa の両方に対応（以前のスタジオ設定 .json も読み込めます）。旧形式 .kinniku の読み込みは廃止しました。
- 季節の演出は名義・キャラクターを切り替えても変わらなくなりました。量・速さ・大きさ・濃さは季節ごとに保持します。
- 画像のプリセット：降らせる画像（最大6枚）・画像の動き・量・速さ・大きさ・濃さを名前付きで何件でも保存できます（30件まで）。季節の演出と同じ欄から選べます。以前の「好きな画像」は「画像 / 好きな画像」として引き継ぎます。

## 0.4.8 で変わったこと

- 画面の配置：映像の右に「音のお品書き」を置きました。映像の欄は映像の幅＋余白だけの幅になります。「表情と演出」と「窓辺の映像演出」は「設定」へ移しました（設定画面にも映像のプレビューを表示します）。映像の下の「表情と演出の設定」ボタンからも開けます。
- 立ち絵の動き：歌うゆらぎ・ぴょんぴょん・ガタガタ・話すときの動きを作り直しました。傾きは画面上での頭の移動量から決めるため、大きくした立ち絵でも振れすぎません。動きの切り替えはなめらかにつながります。大きさ（歌うゆらぎは速さも）をそれぞれ設定できます（キャラクターごとに保存）。立ち絵の縦横比は変えません。
- 季節の演出：量・速さ・大きさ・濃さ・画像の動きを季節ごとに保存します。
- 映像のなめらかさを30／15／10fpsから選べます。以前は画面の書き換えごと（60Hzの画面なら毎秒60回）に描いていたため、30fpsでも描画の回数が減ります。
- 軽量化：立ち絵と背景画像は表示する大きさに縮めた写しを使い回します。軽量モードでは降らせる演出を最大40個にし、画面の飾りのアニメーションと音量メーターの更新を間引きます。

## 0.4.7 で変わったこと

- 立ち絵はどの動きでも縦横比を変えません（伸び縮み・つぶれの表現をすべて廃止し、上下・左右の移動と傾きだけで動かします）。1枚立ち絵の「伸び縮み」は選べなくなり、以前の設定は「弾む」に置き換えます。
- 大きさは10〜500%、左右は±300%、上下は-200〜500%まで動かせます。大きくして頭が切れるときは「上下」を右へ動かすと下がります。上下の数値も表示します。
- 歌枠ノートの「伴奏の音をアプリに取り込む」で、取り込んだ伴奏が約2秒以上の無音のあとに鳴り始めると、BGMと効果音を自動でフェードアウトします（切り替え可。環境音は初期設定では止めません）。伴奏を取り込まない場合用に「歌い始め」ボタンもあります。
- 「音のお品書き」のBGMを1行3列に並べます。

## 0.4.6 で変わったこと

- 立ち絵の透明な余白を自動で詰め、人物の部分を基準に大きさを決めます（キャラクターごとに切り替え可）。大きな透明キャンバスに描いた立ち絵でも小さくなりません。
- 大きさは10〜400%、左右・上下は±150%まで動かせます。大きさの数値を表示します。
- スタジオの「設定を読み込む」で .kissa を選ぶと、効果音・BGMの設定として読み込みます（以前は「ファイルが大きすぎます」になっていました）。

## 0.4.5 で増えたこと

- 名義とキャラクター：名義（初期は「コウサカチヅル」「雪見おと」）ごとに、キャラクターを何体でも登録して切り替えられます。名義を切り替えると、キャラクター・背景の設定・季節の演出・待機／離席画面の設定がまとめて切り替わります。以前の4枚と設定は「コウサカチヅル」の「キャラクター1」に引き継ぎます。
- 1枚だけの立ち絵：表情差分のない画像1枚でも使えます。話すと「弾む／伸び縮み／左右に揺れる」で画像ごと動きます。待機中の呼吸のゆらぎも付けられます（4枚のキャラクターにも使えます）。
- キャラクターごとの背景：専用の背景画像、またはクロマキー等をキャラクターごとに指定できます。
- 効果音のボタンの大きさ：「音のお品書き」の右上で小・中・大を選べます（初期は中）。

## 0.4.4 で増えたこと（「歌枠ノート」の中）

- カラオケ音源を探す：登録したYouTubeチャンネル（初期6件）の中を、YouTubeの検索画面で開きます。別ウィンドウか新しいタブかを選べ、同じ窓を使い回します。チャンネルとメモ（使用条件の控え）は編集できます。
- 伴奏の音をアプリに取り込む：YouTubeなどを開いた別タブの音を、アプリのモニター・録音・動画・配信用の出力に混ぜます。埋め込みは使いません。再生操作はそのタブで、音量はアプリで調整します。パソコン版のChrome・Edge向けです。

## 保存場所

https で開いたときは、同じサイトにある「純喫茶オトノハ」（/Otonoha/）とは別の場所に保存します（混ざらないようにするため）。純喫茶オトノハの効果音・BGMを使う場合は、純喫茶オトノハで設定ファイル（.kissa）を書き出し、こちらの「設定を読み込む」から取り込みます。

端末に保存したHTMLを直接開いた場合は、従来どおりの保存場所を使います。
