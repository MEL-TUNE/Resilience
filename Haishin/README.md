# 配信処オトノハ（テスト版）

PNGTuber（立ち絵の口パク・まばたき）と、声・BGM・効果音・環境音の合成をまとめた、配信・収録用のブラウザアプリです。`index.html` 1ファイルで動きます。

公開場所：https://mel-tune.github.io/Resilience/Haishin/

現在の版：STUDIO 0.10.5（本番にセトリ・企画タブの並び・場面の設定画面・向きを変えたときのマスコットの大きさ）

編集用のソースは `dev/source/` にあります（JavaScript は `js/audio/` と `js/visual/` に機能ごとに分かれています）。`dev` で `python build.py` を実行すると `dev/index.html` ができるので、それをこのフォルダの `index.html` に置きます。

## 0.10.5 で変わったこと

**本番の「🎲 企画」タブ**
- 企画のボタンの下に「🎤 セトリ」を出しました。歌枠ノートのセトリに曲があるときか、歌唱を記録しているときだけ出ます（ふだんの配信では出ません）。「♪ 歌い始め」、音源の「▶」、記録の開始・終了、直前の記録の取り消しができます。歌った曲には ✓、いま歌っている曲は色が付きます。並べ替え・追加・外すのは、これまでどおり「🛠 準備」の歌枠ノートで行います。開け閉めは、このブラウザが覚えます。
- 企画のボタンを「💬 セリフ帳」「🎲 くじ・サイコロ」「📌 お題帳」「📄 アプリ」に分けて並べました。名前は2行までにそろえ、長い名前は、マウスを重ねる（長押しする）と全部出ます。
- 「いま画面に出ているもの」を見出しのすぐ下に、お題の手元カードをボタンのすぐ下に、「ここに並べるものを選ぶ」をいちばん下に移しました。ボタンの中身・押したときの動き・並べる設定は変えていません。

**配信用ウインドウ（OBS 用の別窓）**
- 開くとき、映像の部分がちょうど映像の比率（縦は 9:16、3:4、横は 16:9）になる大きさで開きます。画面に入りきらないときは、比率を保ったまま縮めます。これまでは縦（720×1280）をそのままの大きさで開こうとして画面からはみ出し、比率が崩れていました。
- 映像の向きを切り替えたときも、同じように合わせ直します。
- ウインドウの端をつまんで大きさを変えると、幅に合わせて高さを直し、比率を保ちます。

**設定：準備中・離席中・配信終了の画面**
- 確認用の画面（プレビュー）が上に貼り付いたまま設定を隠していたのを直しました。広い画面では左の列に置き、設定と重なりません。狭い画面では、ほかの項目と一緒に流れます。上に残したいときは「📌 確認用の画面を上に残す」を押すと、小さくして上に残ります（この端末が覚えます）。

**映像の向きを変えたときの、マスコット・ミニキャラの大きさ**
- 大きさは「画面の高さに対する％」なので、横（高さ720）から縦・3:4（高さ1280）へ移ると、同じ％のまま約1.8倍の大きさに見えていました。向きを移るとき、その向きで大きさを自分で直していないものは、画面上の大きさが変わらない％に換算するようにしました。その向きで自分で直した大きさは、そのまま覚えて使います。
- 準備中・離席中・配信終了の画像の大きさも、同じようにしました。
- これまでに保存された控えのうち、ほかの向きの値をそのまま写しただけのもの（大きさが同じもの）は換算します。違う値になっているものは、自分で直したものとしてそのまま使います。

**動画の保存**
- 収録中のデータを、2秒ごとにブラウザ内へ書き足すようにしました。止めるときは目録を書くだけなので、長い収録でもメモリにためこみません。
- 途中で画面が閉じたり固まったりしても、次に開いたときに、そこまでの分を動画として取り戻します（終わりの数秒は欠けることがあります）。

- 収録の前に、ブラウザ内の空きが少ないとき（残り約300MB未満）は知らせます。収録中は、対応しているブラウザで画面が消えないようにします。
- 映像の上に「未収録／● 収録中 0:00」を出します。

**低スペックの環境**
- 描くのが追いつかない状態が6秒ほどつづくと、「動きが重くなっています」と一度だけ知らせ、「軽くする」で軽量モード＋15fps にできます（勝手には変えません。収録中は fps を変えません）。
- 収録の画質に「軽い（容量小・低スペック向け）」を足しました。
- 1枚ずつ開くタブにしたので、画面に並ぶ部品が減りました。

**足した機能**

**狭い画面の直し**

**プログラムの整理**
- 配信・動画の並べ方の CSS を `css/deck.css` にまとめ、`studio.css` から古い並べ方の決まり（0.9.2〜0.9.10 の継ぎ足し）を外しました。

## 0.4.5 で増えたこと

- 名義とキャラクター：名義（初期は「コウサカチヅル」「雪見おと」）ごとに、キャラクターを何体でも登録して切り替えられます。名義を切り替えると、キャラクター・背景の設定・季節の演出・待機／離席画面の設定がまとめて切り替わります。以前の4枚と設定は「コウサカチヅル」の「キャラクター1」に引き継ぎます。
- 1枚だけの立ち絵：表情差分のない画像1枚でも使えます。話すと「弾む／伸び縮み／左右に揺れる」で画像ごと動きます。待機中の呼吸のゆらぎも付けられます（4枚のキャラクターにも使えます）。
- キャラクターごとの背景：専用の背景画像、またはクロマキー等をキャラクターごとに指定できます。
- 効果音のボタンの大きさ：「音のお品書き」の右上で小・中・大を選べます（初期は中）。

## 0.4.4 で増えたこと（「歌枠ノート」の中）

- カラオケ音源を探す：登録したYouTubeチャンネル（初期6件）の中を、YouTubeの検索画面で開きます。別ウィンドウか新しいタブかを選べ、同じ窓を使い回します。チャンネルとメモ（使用条件の控え）は編集できます。
- 伴奏の音をアプリに取り込む：YouTubeなどを開いた別タブの音を、アプリのモニター・録音・動画・配信用の出力に混ぜます。埋め込みは使いません。再生操作はそのタブで、音量はアプリで調整します。パソコン版のChrome・Edge向けです。

## 保存場所

https で開いたときは、同じサイトにある「純喫茶オトノハ」（/Otonoha/）とは別の場所に保存します（混ざらないようにするため）。純喫茶オトノハの効果音・BGMを使う場合は、純喫茶オトノハで設定ファイル（.kissa）を書き出し、こちらの「設定を読み込む」から取り込みます。

端末に保存したHTMLを直接開いた場合は、従来どおりの保存場所を使います。
