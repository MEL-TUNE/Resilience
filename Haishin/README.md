# 配信処オトノハ（テスト版）

PNGTuber（立ち絵の口パク・まばたき）と、声・BGM・効果音・環境音の合成をまとめた、配信・収録用のブラウザアプリです。`index.html` 1ファイルで動きます。

公開場所：https://mel-tune.github.io/Resilience/Haishin/

現在の版：STUDIO 0.6.1（配信画面の幅・ランダムな口パク・秋の絵）

編集用のソースは `dev/source/` にあります（JavaScript は `js/audio/` と `js/visual/` に機能ごとに分かれています）。`dev` で `python build.py` を実行すると `dev/index.html` ができるので、それをこのフォルダの `index.html` に置きます。

## 0.6.1 で変わったこと

- 配信モード（横幅1100px以上）：音のお品書きを約3分の2、配信の操作を約3分の1の幅にしました。
- 口パクの「パクパク」：開けている時間・閉じている時間を、設定した最短〜最長の範囲から毎回ランダムに決めるようにしました。
- 配信・動画モードの秋の演出：降る葉と転がる実を、描き下ろしの絵（葉5枚・実5個）に入れ替えました。絵は `dev/source/js/visual/29-autumn-art.js` に埋め込んでいます。音声モードの動画書き出し（窓辺の映像演出）の秋は変わりません。

## 0.6.0 で変わったこと

- 画面を3つのモードに分けました：配信（OBS）／動画（PNGTuber）／音声（ラジオ）。前回のモードを覚えます（以前の「配信・録画」を使っていた場合、PCでは配信、スマホ・タブレットでは動画で開きます）。
- 配信モード：マイクの声はこのアプリから出さず、口パクの判定にだけ使います（OBSでマイクを直接取り込む前提）。アプリが出す音は効果音・BGM・環境音だけです。動画の収録欄・伴奏タブの取り込み・全画面ボタンを出さず、プレビューは画面の下に小さく表示します。歌枠ノートと企画・AI連携はそのまま使えます。
- 配信用の映像ウインドウ：キャンバスと同じ大きさ（1280×720なら画面上で1280×720ピクセル）の、余白や文字のないウインドウを開きます。
- 状態の切り替え（配信中・準備中・離席中・配信終了）を大きな色分けボタンにし、今の状態を色付きで表示します。すぐ下に「BGMを止める」「効果音とBGMをすべて止める」を置きました（配信・動画モード）。
- 口の動きを選べるようにしました：声が出ているあいだ開けたまま／パクパクを繰り返す（速さも調整可）。
- 動画モード：これまでの「配信・録画」の収録機能はこちらで使います。

## 0.4.8 で変わったこと

- 画面の配置：映像の右に「音のお品書き」を置きました。映像の欄は映像の幅＋余白だけの幅になります。「表情と演出」と「窓辺の映像演出」は「設定」へ移しました（設定画面にも映像のプレビューを表示します）。映像の下の「表情と演出の設定」ボタンからも開けます。
- 立ち絵の動き：歌うゆらぎ・ぴょんぴょん・ガタガタ・話すときの動きを作り直しました。傾きは画面上での頭の移動量から決めるため、大きくした立ち絵でも振れすぎません。動きの切り替えはなめらかにつながります。大きさ（歌うゆらぎは速さも）をそれぞれ設定できます（キャラクターごとに保存）。立ち絵の縦横比は変えません。
- 季節の演出：量・速さ・大きさ・濃さ・画像の動きを季節ごとに保存します。
- 映像のなめらかさを30／15／10fpsから選べます。以前は画面の書き換えごと（60Hzの画面なら毎秒60回）に描いていたため、30fpsでも描画の回数が減ります。
- 軽量化：立ち絵と背景画像は表示する大きさに縮めた写しを使い回します。軽量モードでは降らせる演出を最大40個にし、画面の飾りのアニメーションと音量メーターの更新を間引きます。

## 保存場所

https で開いたときは、同じサイトにある「純喫茶オトノハ」（/Otonoha/）とは別の場所に保存します（混ざらないようにするため）。純喫茶オトノハの効果音・BGMを使う場合は、純喫茶オトノハで設定ファイル（.kissa）を書き出し、こちらの「設定を読み込む」から取り込みます。

端末に保存したHTMLを直接開いた場合は、従来どおりの保存場所を使います。
