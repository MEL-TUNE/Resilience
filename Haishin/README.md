# 配信処オトノハ（テスト版）

PNGTuber（立ち絵の口パク・まばたき）と、声・BGM・効果音・環境音の合成をまとめた、配信・収録用のブラウザアプリです。`index.html` 1ファイルで動きます。

公開場所：https://mel-tune.github.io/Resilience/Haishin/

現在の版：STUDIO 0.4.8（画面の配置・自然な動き・軽量化）

## 0.4.8 で変わったこと

- 画面の配置：映像の右に「音のお品書き」を置きました。映像の欄は映像の幅＋余白だけの幅になります。「表情と演出」と「窓辺の映像演出」は「設定」へ移しました（設定画面にも映像のプレビューを表示します）。映像の下の「表情と演出の設定」ボタンからも開けます。
- 立ち絵の動き：歌うゆらぎ・ぴょんぴょん・ガタガタ・話すときの動きを作り直しました。傾きは画面上での頭の移動量から決めるため、大きくした立ち絵でも振れすぎません。動きの切り替えはなめらかにつながります。大きさ（歌うゆらぎは速さも）をそれぞれ設定できます（キャラクターごとに保存）。立ち絵の縦横比は変えません。
- 季節の演出：量・速さ・大きさ・濃さ・画像の動きを季節ごとに保存します。
- 映像のなめらかさを30／15／10fpsから選べます。以前は画面の書き換えごと（60Hzの画面なら毎秒60回）に描いていたため、30fpsでも描画の回数が減ります。
- 軽量化：立ち絵と背景画像は表示する大きさに縮めた写しを使い回します。軽量モードでは降らせる演出を最大40個にし、画面の飾りのアニメーションと音量メーターの更新を間引きます。

## 0.4.7 で変わったこと

- 立ち絵はどの動きでも縦横比を変えません（伸び縮み・つぶれの表現をすべて廃止し、上下・左右の移動と傾きだけで動かします）。1枚立ち絵の「伸び縮み」は選べなくなり、以前の設定は「弾む」に置き換えます。
- 大きさは10〜500%、左右は±300%、上下は-200〜500%まで動かせます。大きくして頭が切れるときは「上下」を右へ動かすと下がります。上下の数値も表示します。
- 歌枠ノートの「伴奏の音をアプリに取り込む」で、取り込んだ伴奏が約2秒以上の無音のあとに鳴り始めると、BGMと効果音を自動でフェードアウトします（切り替え可。環境音は初期設定では止めません）。伴奏を取り込まない場合用に「歌い始め」ボタンもあります。
- 「音のお品書き」のBGMを1行3列に並べます。

## 0.4.6 で変わったこと

- 立ち絵の透明な余白を自動で詰め、人物の部分を基準に大きさを決めます（キャラクターごとに切り替え可）。大きな透明キャンバスに描いた立ち絵でも小さくなりません。
- 大きさは10〜400%、左右・上下は±150%まで動かせます。大きさの数値を表示します。
- スタジオの「設定を読み込む」で .kissa を選ぶと、効果音・BGMの設定として読み込みます（以前は「ファイルが大きすぎます」になっていました）。

## 0.4.5 で増えたこと

- 名義とキャラクター：名義（初期は「コウサカチヅル」「雪見おと」）ごとに、キャラクターを何体でも登録して切り替えられます。名義を切り替えると、キャラクター・背景の設定・季節の演出・待機／離席画面の設定がまとめて切り替わります。以前の4枚と設定は「コウサカチヅル」の「キャラクター1」に引き継ぎます。
- 1枚だけの立ち絵：表情差分のない画像1枚でも使えます。話すと「弾む／伸び縮み／左右に揺れる」で画像ごと動きます。待機中の呼吸のゆらぎも付けられます（4枚のキャラクターにも使えます）。
- キャラクターごとの背景：専用の背景画像、またはクロマキー等をキャラクターごとに指定できます。
- 効果音のボタンの大きさ：「音のお品書き」の右上で小・中・大を選べます（初期は中）。

## 0.4.4 で増えたこと（「歌枠ノート」の中）

- カラオケ音源を探す：登録したYouTubeチャンネル（初期6件）の中を、YouTubeの検索画面で開きます。別ウィンドウか新しいタブかを選べ、同じ窓を使い回します。チャンネルとメモ（使用条件の控え）は編集できます。
- 伴奏の音をアプリに取り込む：YouTubeなどを開いた別タブの音を、アプリのモニター・録音・動画・配信用の出力に混ぜます。埋め込みは使いません。再生操作はそのタブで、音量はアプリで調整します。パソコン版のChrome・Edge向けです。

## 保存場所

https で開いたときは、同じサイトにある「純喫茶オトノハ」（/Otonoha/）とは別の場所に保存します（混ざらないようにするため）。純喫茶オトノハの効果音・BGMを使う場合は、純喫茶オトノハで設定ファイル（.kissa）を書き出し、こちらの「設定を読み込む」から取り込みます。

端末に保存したHTMLを直接開いた場合は、従来どおりの保存場所を使います。
