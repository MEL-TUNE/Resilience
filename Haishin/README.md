# 配信処オトノハ（テスト版）

PNGTuber（立ち絵の口パク・まばたき）と、声・BGM・効果音・環境音の合成をまとめた、配信・収録用のブラウザアプリです。`index.html` 1ファイルで動きます。

公開場所：https://mel-tune.github.io/Resilience/Haishin/

現在の版：STUDIO 0.9.0（オトノハ連携・AI観客席（手渡し）・ボイス録り）

編集用のソースは `dev/source/` にあります（JavaScript は `js/audio/` と `js/visual/` に機能ごとに分かれています）。`dev` で `python build.py` を実行すると `dev/index.html` ができるので、それをこのフォルダの `index.html` に置きます。

## 0.9.0 で変わったこと

- オトノハ連携（Otonoha Bridge 1）を追加しました。企画卓に登録したHTMLアプリは、window.postMessage で決まった形の伝言を送ると、配信画面にセリフ（吹き出し）・サイコロ・ルーレット・コメントを出せます。利用者が許可したアプリだけ、効果音を鳴らす・場面（配信中・準備中・離席中・配信終了）を切り替えることもできます。オトノハからは、歌い始め・場面の切り替え・配信者が話し始めた／話し終えた・セリフ・サイコロ／ルーレットの結果・AI観客席のコメントなどの出来事を、購読したアプリに送ります。決まりの説明（dev/otonoha-bridge-1.md）と見本アプリ（dev/otonoha-bridge-sample.html）は、企画卓の「オトノハ連携（アプリを作る人向け）」からも保存できます。登録アプリの枠以外からの伝言は受け付けず、1秒に20件を超える伝言は捨てます。
- 企画卓に「AI観客席」を追加しました。AI観客席 0.8 の人物（初期の5人）・性格値の解釈・依頼文・返答の検証の規則を移し、つなぎ先は「手渡し」（依頼文をコピーしてChatGPT／Claudeに貼り、返ってきたJSONを貼り戻す）にしました。配信者の発言と、オトノハの出来事（歌い始めた曲、セリフ、サイコロ・ルーレットの結果、場面の切り替え）が依頼文に入ります。コメントは配信画面の端（右・左）に流れ、配信用ウインドウ・収録する動画にも映ります。人物の編集（名前・一人称・話し方・してはいけないこと・性格値15項目・話し方の例）と、AI観客席（exe）の人物バックアップ（ai-audience-backup version 1）の読み込み・書き出しができます。Ollama・LM Studio・APIは今後追加します。
- 「AIキャラ・声」のタブを追加し、「ボイス録り」を入れました。読み上げる文を1文ずつ表示して録音し（ブラウザの音声加工を切ったマイク）、音割れ・声の小ささ・雑音・短すぎを確かめ、前後の無音を詰めて保存します。録音は、1文1ファイルのWAV（モノラル・16bit）と「ファイル名|話者名|JP|文」の一覧（esd.list）にまとめて、ZIPで書き出せます。学習（声のモデルづくり）はこのアプリでは行いません。

## 0.8.1 で変わったこと

- 企画卓に「セリフ帳」を追加しました。シチュエーションごとにセリフ（1行に1つ、最大300個）をためておき、「ランダムに出す」「前・次」で配信画面に吹き出しで出します。ランダムは、全部出し終えるまで同じセリフを繰り返しません。「AIに頼む文をコピー」で、企画卓の「AIに渡す設定・依頼」とシチュエーションを入れた依頼文を作れます。返ってきたセリフを貼り付けると、番号・記号・かぎかっこを外して足します。吹き出しの位置（下・上・左下・右下）と、名義の名前を添えるかを選べます。
- 企画卓に「ルーレット・サイコロ」を追加しました。サイコロは1〜3個、4・6・8・10・12・20面と1〜100から選べ、振ると転がってから止まります（2個以上は合計も出します）。ルーレットは2〜24個の項目を入れて回すと、減速して針の位置で止まり、結果を出します。出目と止まる項目は、毎回ブラウザの乱数（crypto.getRandomValues）で決めます。
- セリフの吹き出し・サイコロ・ルーレットは、配信画面に描くので、配信用ウインドウ・アプリと立ち絵のウインドウ・収録する動画にも映ります。

## 0.8.0 で変わったこと

- 企画卓に「アプリを並べる」を追加しました。HTMLで作ったアプリ（AITuberアプリ、セリフを出すゲームなど）を、HTMLファイルかURLで最大12個まで登録し、企画卓の中で開けます。横に立ち絵（配信画面と同じ絵）が出ます。
  - 「アプリと立ち絵を別ウインドウで開く（OBS用）」で、アプリの画面に立ち絵を重ねる（右下・左下・右上・左上）か横に並べたウインドウを作れます。立ち絵の大きさはウインドウの幅の15〜70%です。重ねるときは背景を「透過」にすると立ち絵だけが重なります。
  - 別ウインドウで開いている間は、企画卓の中のアプリを止めます（同じアプリが二重に動かないように）。
  - 登録したHTMLファイルはこのブラウザ内に保存します（.live には入りません）。既定では、アプリの中の保存・マイクが使える形で開きます。切ると、このページから隔離して開きます。
- 歌枠ノートの「これまでの記録」の回ごとに「概要欄を作る」を追加しました。アーカイブのURLと、各曲の時刻（12:34 や 1:02:03）をあとから入れると、概要欄にそのまま貼れるセットリストの文ができます。「時刻リンクつきでコピー」で、YouTubeの時刻リンク（https://youtu.be/…?t=秒）を添えた文も作れます。見出しと、時刻を入れていない曲の扱い（曲名だけ載せる／記録した経過時間を使う／載せない）を選べます。
- 「♪ 歌い始め」で、配信画面（配信用ウインドウ・収録する動画も同じ）に曲名と歌手名を出せるようにしました。いま歌っている曲だけ、またはこれまでの曲（最新8曲）を、四隅のどこかに出します。出しておく時間と文字の大きさを選べ、「画面の曲名をいったん消す」で消せます。
- 着せ替えの色を調整しました：プリンアラモード（カスタードの黄色・カラメルの焦げ茶・さくらんぼの赤）、オムライス（卵の黄色・ケチャップの赤・デミグラスの茶色。ナポリタンの桃色・橙・緑と分けました）、コーヒーゼリー、夜のクリームソーダ。

## 0.7.6 で変わったこと

- 立ち絵の「右往左往」：止まっては歩く形をやめ、周期の違うゆっくりした揺れを重ねて、止まらずに左右をうろうろする動きにしました。速さも向きの変わり目もなめらかにつながります。歩くときの上下の弾みはなくしました。
- 立ち絵の「いやいや」：休みを挟む形をやめ、小刻みに左右へ揺れ続ける動きにしました。揺れの速さと大きさを、ゆっくり変わる揺らぎで少しずつずらし、規則的に見えないようにしています。
- マスコットの「お散歩」：左右だけに歩く形をやめ、ぴょこぴょこ跳ねながら、行き先を次々に変えて上下左右あちこちへ進む動きにしました。向きはなめらかに曲がって変わり、ときどきその場で小さく跳ねて休みます。
- どの動きも、画像の左右反転や縦横比の変更は使っていません。
