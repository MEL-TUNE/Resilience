# 純喫茶オトノハ

声・BGM・効果音・環境音をその場で合成して録音する、ブラウザで動くアプリです。`index.html` 1ファイルで動きます。

公開場所：https://mel-tune.github.io/Resilience/Otonoha/

## できること

- 絵文字の効果音（6列）・文字の効果音（5列）・ボイス（5列・画像つき）：最後の行まで埋まると枠が1行増えます
- 鳴っている間にもう一度押したときの動きを、ボタンごとに選べます（おまかせ／最初から鳴らす／重ねて鳴らす／止める）。おまかせでは、絵文字の効果音は8秒未満なら見出し横の設定どおり、8秒以上なら止まります。文字の効果音は止まります
- 「■ 全音停止」と「■ 効果音＋環境音」（BGMとボイスは残す）を、録音欄と、スクロール中に上へ出る小さな操作欄の両方に置いています。各欄へ移動するボタンもあります
- 環境音（8枠）：ループ再生。BGMと重ねて流せます
- BGM：ジャンル別の5タブ×20曲
- 番組（8つ）：番組ごとに初期BGM・ボタンの色・動画用サムネイル（8枚）。番組ボタンの長押し（パソコンでは右クリック）で設定を開きます
- 録音：マイクの声とBGM・効果音・環境音を合成して録音。WAV・MP3・動画（WebM／MP4）で書き出し
- 書き出した動画はブラウザ内にも残り、テイクの欄の「端末に保存」「共有・写真アプリへ」（対応端末のみ）から、作り直さずに保存し直せます。動画サイズは 1080／720／540
- 映像の演出（設定画面）：春「はらはら桜」・夏「ぷくぷくソーダ」・秋「ころころ木の実」・冬「ふわふわ白雪」。標準の絵か、好きな画像を動かせます。8・15・30コマ／秒
- 名前と着せ替え（設定画面）：看板の文字・タイトル・サブタイトル・各欄の見出しの名前、喫茶メニューの配色8種とカスタム
- 使う機能（設定画面）：「収録機能を使わない」を入れると、効果音・BGM・環境音を鳴らすだけの画面になります（マイクにはつなぎません）

## 設定ファイル（.kissa）

「設定 → 設定を書き出す」で、効果音・ボイス・環境音・BGM・サムネイル・動かす画像・名前と着せ替えを1つの `.kissa` ファイルにまとめます。別の端末では「設定を読み込む」から取り込めます。

- 録音したテイクと、書き出した動画は含まれません。必要なものは端末に保存してください。
- 以前の `.kinniku` 形式は読み込めません。

## 保存場所

設定・音源・録音は、開いているブラウザの中に保存されます。ブラウザやURLが変わると引き継がれないため、設定ファイルで持ち運んでください。保存先は同じリポジトリの Soundboard・Recording とは別です。

## 動作環境

- マイクは https で開いたページで使えます（上の公開場所）。端末に保存したHTMLを直接開くと、ブラウザによってはマイクが使えません。
- 動画の書き出しは WebCodecs に対応したブラウザ（最新のChrome・Edgeなど）で動きます。
- MP3変換の部品は、初回にインターネットから読み込みます。
- 録音中と動画の書き出し中は、対応しているブラウザでは画面が自動で消えないようにします。
- 動画は、書き出しが終わるまで端末のメモリに持ちます。長い録音では、作る前に大きさの見込みを表示します。
