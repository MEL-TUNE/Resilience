# 純喫茶オトノハ — 改良版 0.2

添付いただいたHTMLを元にした修正版です。`index.html` 1ファイルで使えます。元ファイルは変更していません。

## 変更内容

- 深緑の看板、クリーム色の紙面、真鍮色の縁取り、明朝体とメニュー表風の見出しに調整。スマートフォンの縦並びにも対応。
- 既存の名前・配色設定は優先して保持。「設定 → 名前と着せ替え」で「抹茶ラテ」を選ぶと新しい配色に変更できます。
- 「収録したテイク → 窓辺の映像演出」に、雪・好きな画像の降下演出を追加。量・速さ・大きさ・不透明度、24/30コマを選べます。透過PNGにも対応。
- プレビューと書き出しに同じ描画処理を使用。演出なしは従来通り毎秒1コマで軽量化。
- 動画の書き出し中止、同時書き出しの制限、書き出し中のテイク削除防止を追加。
- 移行ファイルに降下演出の画像も保存。ヘッダー・データ範囲の検証と重複する音源の書き出し抑制を追加。
- ダイアログのフォーカス管理・Tab移動・Escで閉じる操作を追加。短い録音のMP4音声確認判定を修正。

## 使い方

1. 収録したテイクを用意します。
2. 「動画用サムネイル」で背景画像を選びます。画像なしでもタイトル入りの背景になります。
3. 「窓辺の映像演出」で「雪」または「好きな画像」を選びます。好きな画像を選んだ場合は、降らせる画像も登録します。
4. 「演出をプレビュー」で共通サムネイル上の動きを確認します。
5. テイクの「動画を書き出す」を押します。テイク専用画像、番組画像、共通画像の順に使われます。

最新のデスクトップ版Chrome / Edgeを推奨。MP4を利用できる場合はMP4、利用できない場合やMP4音声検証が失敗した場合はWebMになります。動画演出は静止画より処理時間・容量・メモリを使います。まず720pxの短い録音でお試しください。MP3変換部品の初回読み込みにはネット接続が必要です。

## 移行について

既存アプリの「設定を書き出す」で引き継ぎファイルを残し、修正版の「設定を読み込む」から読み込んでください。以前の `.kissa` / `KNKRPACK` 形式と対応する旧JSON形式の読み込み処理は保持しています。

**設定の引き継ぎファイルには、収録済みテイクの音声は含まれません。** 必要なテイクは移行元からWAV等でも保存してください。保存先URL・ブラウザ・プロファイルが変わると、ブラウザ内のデータは自動で引き継がれません。

マイクはHTTPSまたはlocalhostで利用する構成が確実です。HTMLの直接起動では、ブラウザにより録音・保存・動画書き出しの利用可否が異なります。

## 名前の変更（0.2の後）

- 初期の名前を「純喫茶オトノハ」に、配色「純喫茶の書斎」を「抹茶ラテ」に変更。看板の「♨」を削除。
- 画像なしで動画を書き出すときの背景の文字は、固定の英字と決め文句ではなく、設定画面のサブタイトルを使うよう変更。

## 季節の演出（0.2の後）

- 「季節の演出」で動きを選びます：春「はらはら桜」（花びらが舞い散る）、夏「ぷくぷくソーダ」（泡が下から湧き出て昇る）、秋「ころころ木の実」（画面の下を元気に跳ねて転がる）、冬「ふわふわ白雪」（ゆったり降る雪）。
- 「動かすもの」で、標準の絵（花びら・泡・どんぐり・雪）か、登録した好きな画像かを選びます。好きな画像も、選んだ季節の動きで動きます。
- 以前の設定の「雪」は冬・標準の絵に、「好きな画像」は冬・好きな画像に読み替えます。

## 検証済みの範囲

（ChatGPT版0.2の時点の記録）`node verify.cjs` と `node video-check.cjs` が通過していました。この2つの検証ファイルは旧い演出を前提にしているため、ここには含めていません。JavaScript構文、静的ID重複、設定値の制限、既存音源の移行、雪・画像の時間に応じた描画、移行ファイルの破損検出、24/30fps・静止画のフレーム生成、中止とエンコーダー解放を確認しています。

動画パイプラインの検証ではコーデックAPIを模擬しています。作業環境の権限制限によりブラウザを起動できず、画面の実表示、実マイクでの録音、実コーデックで書き出した動画の再生、長時間収録、Safari / iPhoneでの動作は未確認です。販売版としての動作保証を示すものではありません。
